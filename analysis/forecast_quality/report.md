## Качество сохранённых прогнозов матчей

Каждая игра считается один раз. В таблице калибровки вероятность берётся со стороны фаворита, условно на отсутствие ничьей; результат — победа фаворита. Поэтому процент побед можно сопоставлять напрямую с диапазоном прогноза. Интервалы — Wilson 95%; Brier и log loss считаются по решённым матчам; эталон 50/50 имеет Brier 0.250 и log loss 0.693. Интервалы и paired bootstrap рассчитаны на уровне игр без поправки на повторное участие тех же команд, поэтому неопределённость может быть занижена.

Сохранённый `win_prob` в team scenarios — per-game прогноз с 70% веса победного процента и 30% past SoS, домашней вероятностью, ограниченной 25–75%, и ничьей 0.3%. - Найдено пригодных snapshot сценариев: 36 Madden 26 и 23 Madden 27.
- Завершённых уникальных игр с сохранённым прогнозом: 283.
- На этих завершённых играх убрано повторных прогнозных snapshots: 1480.
- Исключено Force Win: 8; ничьи: 0 (не входят в бинарные метрики).
- Основная выборка регулярки: 269; postseason отдельно: 6.
- Результат ещё не появился в финальном циклическом snapshot: 60 уникальных игр; они не оценивались.
- Для чистого ELO пригодно: 118 матчей по всем фазам; после Force Win/postseason фильтров сравниваются 108 регулярных матчей; пропущено по сроку/рейтингу: 165.
- Не связаны с единственной строкой расписания либо не прошли проверку зеркальных прогнозов: 0 кандидатных записей.
- Madden 27 активный result snapshot: `4b7c9d123bc35e77`; метаданные обозначают `exportWeekIndex=15`, `completedThroughWeek=16`, `eloSourceWeek=8`.
- Madden 26 terminal evidence: commit `4a5ee61fc7e8`; Madden 27 result evidence: commit `7a6deb4ea63c`.
- Прогнозный статус взят из того же коммита, что и JSON; матч имел незавершённый status. У большинства исторических игр нет точного `scheduled_date_time`, поэтому по Git нельзя доказать wall-clock порядок относительно реального kickoff, только то, что на момент генерации прогноза committed экспорт ещё считал матч незавершённым.
- Выборки по сезону и версии модели не объединяются. ELO сравнивается только с rating column из того же snapshot и только после его источниковой недели.
- Смешанная реконструкция Madden 27: 48 матчей; не восстановлено из-за неподдержанного source hash/недостатка snapshot данных: 0.
- Для Madden 26 по game-level probability JSON доступны только seasonIndex=2 и 3; сохранённых match probabilities для сезонов 0 и 1 в пригодных snapshot не найдено.
- Madden 26 regular ELO сравнение есть только там, где сохранились contemporaneous Week 14+ ratings; для более ранних матчей и части сезона 3 рейтинги появились позднее и исключены.
- `team_scenarios.json` хранит округлённые десятые доли процента. Расчёт модели реконструирован из исторических файлов, не запуском старых скриптов. Явно сохранённые проценты не заменены.

## Рекомендации

1. Не менять +75 только по текущей выборке: Madden 26 и Madden 27 дают разный знак разницы, а интервалы неопределённости широкие. Сохранить значение как рабочую настройку до накопления нескольких независимых сезонов.
2. Продолжать сохранять перед каждым туром матчевые вероятности, source ELO week, snapshot ID, версию формулы и точное время; так будущая выборка станет действительно предматчевой.
3. Для калибровки playoff/SB собирать отдельные preseason/round-by-round прогнозы вместе с посевом и фактическим bracket; оценивать чемпионские шансы только после многих сезонов.
4. Не подбирать шкалу ELO или бонус на этих же матчах. Если настройка понадобится, выделить ранние сезоны для обучения, а более поздние сезоны держать как хронологический holdout.
